# Portfolio Website — Project Plan

## Purpose
Create a professional, responsive portfolio that introduces a web development student, shares selected work, and makes contact information easy to find.

## Audience and goals
- **Audience:** employers, internship coordinators, potential clients, course tutors, and peers.
- **Goals:** introduce the developer; show real projects and skills; provide a contact method; work clearly on desktop, tablet, and mobile; support keyboard and assistive technology use.

## Page outline
- Home: name, role or learning focus, and introduction.
- About: background, interests, and learning goals.
- Skills: tools the developer has actually used.
- Projects: project title, summary, contribution, and eventual link.
- Contact: a contact method the developer chooses to publish.

## Content and assets
Replace the bracketed text in `index.html` with accurate details. Gather project names, summaries, contribution notes, links, and any images that may be shared. Only use images you own or have permission to use. The current project art is generated placeholder imagery.
